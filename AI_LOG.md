# Работа с ИИ

**Инструмент:** OpenCode, модель `openai/gpt-6-sol`. 

**Ключевые запросы:**

Создание архитектуры:
```text
Предложи архитектуру сервиса строго по тз. Придерживайся архитектуры: разделение на сервисы, репозитории, модели.
```
Начальный промпт:
```text
Реализуй проект строго по требованиям, описанным в тз, кроме всего того, что ниже четвёртого пункта включительно. Архитектуры придерживайся своей, но используй postgresql (пока напиши просто гипотетическое подключение к ней, саму бд потом добавим). Константы храни в отдельном каталоге `/constants` в файле `payments.py`. 

'models' создавай на основе `sqlalchemy`, 'schemas' на основе `sqlalchemy`. Добавь валидацию для `email`, поля `status`, `method`, `installment_months` могут принимать только значения, указанные в тз, с помощью `Literal`.

Саму бд пока не разрабатывай. Используй строгую типизацию. README.md и AI_LOG.md не трож. Всё, что сейчас лежит в корне проекта можешь менять
```
БД:
```text
Создай базу данных с помощью docker-compose. Переменные окружения для БД бери из `.env`. Добавь healthcheck каждые 30 секунд.
Таблицы пока не создавай.

Сервис тоже оберни в него, установку зависимостей, запуск сервиса  автоматизируй с помощью dockerfile.
```

**Ошибки и правки:** 
- сначала (после промпта "Начальный промпт") ассистент предложил `seed()` для записи тарифов при старте, хотя в проекте требовалось читать их из БД. После замечания метод удалили. 
- Промокод асистент хранил как константу. Решил создать отдельную талицу для них и также читать её при старте сервиса

- В тестах асистент не написал проверку schedule с применёным промокодом, поэтому попросил добавить
